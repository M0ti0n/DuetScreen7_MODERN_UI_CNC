# DuetScreen


Modern UI CNC for Duet 3d Duet Screen 7  is the touchscreen UI for Duet3D displays focusing on CNC mills and routers machines running RepRap Firmware. Built with LVGL. It runs on [Duet3D screen hardware](https://docs.duet3d.com/Duet3D_hardware/Accessories/DuetScreen) and can also be compiled for x86/Arm on Linux and macOS to support development and testing.
