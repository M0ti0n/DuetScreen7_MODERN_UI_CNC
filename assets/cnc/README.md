# CNC UI assets

- `LiberationSans-Regular.ttf`: the typeface of the PanelDue CNC UI fonts (glcd19x21 and
  glcd28x32 are Liberation Sans rasterised by MikroElektronika GLCD Font Creator).
  Used at 24 px and 36 px (PanelDue sizes x 1.25). SIL Open Font License 1.1, see
  `OFL-LiberationSans.txt`. Kept here rather than in `assets/fonts/` so it does not appear in
  DuetScreen's own font menu.
